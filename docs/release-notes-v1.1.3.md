## 码典 CodeAtlas v1.1.3

修一个把导入卡死的问题，顺带把知识包面板补上两个一直该有的按钮。

### 修了什么：一条链接写法能拦住整个包

反馈是这样的 —— 导入停在

> 有 1 处要改，改完再校验：`categories[0].items[0]` 的 `docs.src.u` 必须是 https 链接

改完还是过不去。查下来这条校验只看字面 `https://` 前缀，有三个问题：

- **前导空格、大写 `HTTPS://`、中文冒号 `：`、反斜杠全被当成错** —— 这些从 AI 复制的文本里极常见；
- **`http://` 和漏写协议一律硬拦**，可它们并不是「不能用」；
- **提示既不显示实际值，也不说是哪一条** —— `categories[0].items[0]` 没人能数出是哪条。

现在分档处理：

| 写法 | 处理 |
|---|---|
| 规范 `https://…` | 原样保留 |
| 前导/尾随空格 · 大写协议 · 中文冒号 · 反斜杠 · `//host/x` · `host/x` | **自动修正**，导入照常通过，附一条「已自动修正」提示 |
| `http://…` | 保留原值（有的站只有 http，瞎升级会变死链），提示建议换 https |
| 空值 / 纯空格 | 当作没写，忽略 |
| 完全不像链接（如 `docs/README.md`） | 仍然拦下，但提示带**实际值**和**片段标题** |

另外 `docs` 写成 `{ src: "https://…" }`（AI 常见写法）现在也能识别。

### 加了什么：粘贴 / 清空

换一份新包不用再手动全选删除了：

- **粘贴** —— 一键读剪贴板。桌面版走主进程，网页版走 Clipboard API，
  都读不到就把光标放回框里提示按 `Ctrl+V`，不报错。
  粘贴是**替换**而不是追加 —— 一次导入就是一个包，追加多半是误操作。
- **清空** —— 一键清空。
- 右侧显示「N 字 · N 行」，粘完一眼确认进没进来。
