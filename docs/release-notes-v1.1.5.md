## 可执行任务

带 `task` 字段的预设会展开成任务视图，第一个是**小型办公网三层互通**
（10 个参数 / 3 台设备 / 12 步 / 5 项验证）。

| 以前 | 现在 |
|---|---|
| 每一步各填一遍同一个 VLAN，填错一处就对不上 | 参数集中在顶部填一遍，整份任务共享一个作用域 |
| 所有设备的命令串成一段，粘之前得自己挑 | 按设备分块，块头直接「复制本设备全部」 |
| 配完不知道对不对 | 5 项验证各一个勾，进度条实时算，关掉再开还在 |
| 换一步要重新改一遍 | 参数和主界面共用一份，片段里也认 |

进度存在本机（`codeatlas.task.v1`），「重置进度」不会清参数。

## 「下一步」修掉三处错

- **不再跳过 `quit`**。以前 `port default vlan 10` 之后直接提示下一个接口，
  少敲一条 `quit` 就进错视图 —— 这条最坑，因为报错是后面才出现的。
- **连续导航命令能连消费**。OSPF 主线连着两次 `quit`，原来第二次被吞掉，自检 40/41。
- **悬浮窗自己的复制不再触发重匹配**。点「复制」写回的剪贴板 1.8 秒内被轮询当成新输入，
  面板会跳一下；现在记指纹，自己写的直接跳过。

桌面端左轨也加了「下一步」入口 —— 以前只有知道热键 `Ctrl+Alt+Z` 才找得到。

## 内容层面的硬错误

这些是"照着抄必然不通"的那种错，不是文字瑕疵：

| 位置 | 问题 | 现在 |
|---|---|---|

| MPLS VPN | 两个 CE 同网段，实验本身不成立 | CE2 改独立 `192.168.2.0/24`，补全步骤与验证 |
| IPv6 双栈 | 只有 IPv6 地址，没有 VLAN / IPv4 / OSPFv2 | 全部补齐，验证覆盖两栈 |

| Python 片段 | 直接拼 `json.loads("{{value}}")`，引号一碰就炸 | `json.loads(r"""{{value}}""")` |
