## 码典 CodeAtlas v1.1.2

给网络工程和 JavaWeb 学习者的**中文配置速查库**。电脑、手机、网页三端共用同一份代码，
零依赖、不联网也能用，数据全在本机。

### 这个版本的重点：在 eNSP 里卡住时，按一次键

在 eNSP 控制台里**选中刚敲的几行，按 `Ctrl+Alt+Z`**，悬浮窗直接告诉你：

- **下一步** —— 一句命令，大号字加粗高亮
- **随后** —— 紧接着那一句，以及最容易漏的点
- **整段配置** —— 这一整段可整段复制，按设备分好段
- **最容易错在这** —— 这个场景的坑
- **配完拿这个验** —— `display` 命令 + 期望输出
- **不是这个场景？** —— 按匹配度列出候选，每条标进度（`16/16`）

以前要按两次（先 `Ctrl+C` 再按热键），现在只要按一次 —— 程序替你按那一下复制。
剪贴板能力一个没少：读、写、变化轮询全在。

> **为什么走剪贴板**：eNSP 的 CLI 是自绘控件，里面的文字不属于 Windows 标准文本框，
> Electron、UIA、`WM_GETTEXT` 全都伸不进去；OCR 慢且不稳；系统级键盘钩子破坏性太强。
> 剪贴板是唯一可靠又不引原生依赖的路，而且附带隐私优势 ——
> **程序不监听你敲什么、也不截屏，只读你主动复制的那几行。**

### 质量保障

仓库里 `_dev/` 下有 20 个自检脚本，其中 7 个是纯 Node、可直接命令行跑，已接入 GitHub Actions：

| 脚本 | 检查什么 |
|---|---|
| `check-all.js` | id 唯一、变量闭合、ref 有效、专题归属、**幂等**（跑三遍结果不变） |
| `check-recipes.js` | **视图链检查器**：模拟 VRP 视图栈，抓「命令放错视图」 |
| `check-nextstep.js` | 41 条断言，含 41 个剧本主线批量回推（自己认回自己） |
| `check-search.js` | 25 个查询 + 首条结果断言（`dis isis` 必须命中 `display isis peer`） |
| `check-import.js` | 知识包全链路 34 条断言 |
| `check-copysel.js` | 真开靶子窗口，验证注入的 `Ctrl+C` 确实进了剪贴板 |
| `check-grab.js` | **端到端**：按一次热键 → 自动复制 → 面板拿到内容，全程无人按 `Ctrl+C` |

视图链检查器首跑抓出 4 个真错误，其中一条会把
`ip route-static 0.0.0.0 0.0.0.0 拨号对端地址` 原样粘进设备 —— 用户是照着一行行粘的，这类错必须先拦下来。
